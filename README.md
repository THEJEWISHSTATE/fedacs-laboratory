### 🧠 What is FEDACS?
FEDACS is a framework that dynamically balances exploration (α) and protection (β) based on context coordinates V, S, R, C.

### 🏥 EOSS Therapy
- **EOSS**: Environmental Over Sampling Syndrome (recognized pathology)
- **Treatment**: FEDACS provides algorithmic dosage of α/β
- **Visualization**: Real-time simulation of pathological vs healthy states

### 🎮 Features
- Interactive control panel (V,S,R,C sliders)
- EOSS pathological state simulation
- One-click therapeutic intervention
- Real-time recovery visualization

### 📊 Formula
α = exp(1.0*V - 0.8*S + 0.5*R - 0.9*C) / denominator
β = exp(0.8*S + 0.5*R - 0.7*V + 0.9*C) / denominator
